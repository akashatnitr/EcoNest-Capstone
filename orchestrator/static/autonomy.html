How to read this

Recommendation
An action EcoNest considered after analysing the latest home snapshot.
Confidence
How certain the decision model was. EcoNest only executes actions above the configured safety threshold.
Risk
The potential impact of the action. Low-risk actions are safer candidates for autonomous control.
Model source
ollama means the local model produced the recommendation. fallback_policy means a safe rule was used when the model could not provide a usable answer.
Background monitor
The scheduled autonomous check, rather than a request typed in Command Center.
Outcome
Shows whether an action was executed, skipped by a safety rule, only advisory, or failed. Red is used only for failures.
