How to read this

Recommendation type
EcoNest rotates energy, security, and watering reviews every 10 minutes. Each type runs once per 30-minute cycle.
Risk
The potential impact of an action. Low-risk actions are safer candidates for autonomous control.
Model source
ollama means the local model produced the recommendation. fallback_policy means a safe rule was used when the model could not provide a usable answer.
Background monitor
The scheduled autonomous check, rather than a request typed in User Prompts.
Outcome
Shows whether an action was executed, skipped by a safety rule, only advisory, or failed. Red is used only for failures.
