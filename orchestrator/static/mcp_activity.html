Command Center

How to read this

Task
One complete EcoNest request or autonomous decision. All calls inside the card belong to that task.
Tool
An approved MCP operation that can read data or take an action, such as checking a light or calling Home Assistant.
Resource
Read-only context supplied through MCP, such as a defined capability or system inventory.
Device
The Device Agent: the specialist responsible for safely checking and controlling Home Assistant devices.
Orchestrator
The coordinator that receives a task, selects an agent, and records the final outcome.
Background monitor
The autonomous check that runs on its schedule, rather than a command typed in Command Center.
Completed / failed
Whether that specific MCP call succeeded. A failed audit call does not necessarily mean the device action failed.
